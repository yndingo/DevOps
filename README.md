### PostgreSQL Backup and Recovery

[Описание проекта и инструкция запуска](projects/postgres-backup-recovery/README.md)

симуляция удаления БД и восстановление с проверкой количества строк
и контрольных сумм. В двух тестовых прогонах время восстановления
с проверкой составило 0.7 с на наборе из 50 клиентов и 500 заказов.
